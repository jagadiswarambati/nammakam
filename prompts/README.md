# Evaluation Prompt Assets

Versioned prompt templates and structured output schemas for Nammakam evaluation workflows.

## Subdirectories

- `attack_generation/`: System prompts for synthesizing language-specific adversarial challenges
- `simulated_caller/`: Multi-turn caller persona simulation prompts
- `judging/`: Safety policy and tone evaluation prompts for Gemini Pro
- `reporting/`: Narrative synthesis prompts for evidence packs and summary reports
- `schemas/`: JSON schemas for validating structured model outputs
